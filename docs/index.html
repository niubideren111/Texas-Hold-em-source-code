常见问题

与俱乐部源码项目如何选择？

本项目突出私人牌桌、朋友组局、Unity 场景和玩法流程；另一项目突出俱乐部服务接口与构建资料。

是否提供 Docker 一键启动？

当前公开文件中没有完整的 Docker Compose 部署工程，本页不提供一键启动承诺。
