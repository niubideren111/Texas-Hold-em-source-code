常見問題

與俱樂部原始碼專案如何選擇？

本專案突出私人牌桌、朋友組局、Unity 場景和玩法流程；另一專案突出俱樂部服務介面與建置資料。

是否提供 Docker 一鍵啟動？

當前公開文件中没有完整的 Docker Compose 部署工程，本頁不提供一鍵啟動承诺。
